# @overlay/tools-core

Tool definitions, exposure policy, MCP schema-to-Zod conversion, and internal API tool helpers for Overlay.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/tools-core
```

## Usage

```ts
import { toolDefinitions } from '@overlay/tools-core'
```
