# @overlay/auth-contracts

Shared authentication types and error contracts used across Overlay clients and servers.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/auth-contracts
```

## Usage

```ts
import { OverlayAuthError } from '@overlay/auth-contracts'
```
