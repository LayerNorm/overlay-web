# @overlay/chat-core

Chat turn state, messages, generated UI, and rendering helpers for Overlay conversations.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/chat-core
```

## Usage

```ts
import { ChatState } from '@overlay/chat-core'
```
