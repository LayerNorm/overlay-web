# @overlay/app-core

Core application contracts, capabilities, and module registry for the Overlay web app.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/app-core
```

## Usage

```ts
import { capabilities } from '@overlay/app-core'
```
