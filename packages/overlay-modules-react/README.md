# @overlay/modules-react

React feature modules for knowledge, notes, projects, settings, automations, and extensions in the Overlay app.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/modules-react
```

## Usage

```tsx
import { KnowledgeModule } from '@overlay/modules-react/knowledge'
```
