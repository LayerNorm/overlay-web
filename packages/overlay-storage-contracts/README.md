# @overlay/storage-contracts

Shared storage contracts and types used by the Overlay storage adapters.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/storage-contracts
```

## Usage

```ts
import { storageContracts } from '@overlay/storage-contracts'
```
