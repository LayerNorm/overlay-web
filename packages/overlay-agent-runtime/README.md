# @overlay/agent-runtime

Runtime helpers for executing AI agent turns, managing tool registries, and persisting turn state in Overlay.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/agent-runtime
```

## Usage

```ts
import { agentRuntime } from '@overlay/agent-runtime'
```
