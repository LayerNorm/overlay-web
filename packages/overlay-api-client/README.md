# @overlay/api-client

Typed client for Overlay's public `/api/v1` web API.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/api-client
```

## Usage

```ts
import { createOverlayApiClient } from '@overlay/api-client'
```
