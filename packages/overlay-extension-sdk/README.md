# @overlay/extension-sdk

SDK for building Overlay extensions and custom modules.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/extension-sdk
```

## Usage

```ts
import { defineExtension } from '@overlay/extension-sdk'
```
