# @overlay/billing

Billing, entitlements, quota enforcement, and usage metering contracts for Overlay.

## Install

This package is part of the Overlay workspace. Import it from the workspace root:

```bash
npm install @overlay/billing
```

## Usage

```ts
import { entitlements } from '@overlay/billing'
```
