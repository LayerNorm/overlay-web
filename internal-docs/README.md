# Internal Documentation

This directory contains engineering material that is useful in the repository
but must not be published on the Mintlify site.

## Contents

- `aws-rehearsals/` contains AWS validation plans, fault-injection procedures,
  evidence requirements, and rehearsal findings.
- `on-prem-parity/` contains numbered implementation phases, architecture
  status, and backend parity test procedures.
- `reports/` contains generated audits and engineering reports.
- `design-assets/` contains internal reference images.

Customer-facing deployment, security, operations, and upgrade instructions live
under `docs/`. Promote reusable guidance there only after removing customer
identifiers, branch names, phase numbers, rehearsal history, and internal
evidence paths.
