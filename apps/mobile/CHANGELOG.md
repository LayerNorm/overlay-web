# Changelog

## Unreleased

- Add native menus to the Chats list. Touch and hold a personal chat to rename it (in an iOS text prompt), archive it or delete it (with a confirmation); a channel or direct message to archive it; or an agent to open its chat or its settings. Archived and deleted chats leave the list at once. New message and New channel open as iOS form sheets with Cancel and ✓, a searchable people list and a Public/Private switch, and open the new conversation when done (creating a channel used to leave you on the Chats list). Adding people from a room's Members uses the same sheet. Archived is a native list with the system search bar; touch and hold to unarchive, or delete a personal chat. It now also shows archived channels and direct messages, which mobile couldn't bring back before, and opens each one as the right kind of room.
- Make Work's sheets native. New task opens as an iOS form sheet with Cancel and ✓, a title and description, menu pickers for assignee, status and priority, date switches with the native date picker, and a Depends on menu you can tick several tasks in. A task's page is now a native form: tap the title or description to edit it in place (✓ in the bar saves, and the description shows its Markdown formatting), change status and assignee from menus, set dates with the date picker, pick dependencies, mark it done, read the activity and post a comment. Touch and hold a task in the list or board to move it to another column, to the top or bottom of its column, or to schedule it, which opens a native sheet with the dates and "a day earlier / later". Organization is a native page with a Workspace/Personal switch, and tapping an agent opens it directly. This removes the hand-drawn Work sheets, typed YYYY-MM-DD dates and the board's separate Move button.
- Make rooms (direct messages, channels and threads) use native iOS menus and sheets. Touching and holding a message opens the system context menu (the message lifts, like Messages) with a React submenu of 8 emoji, Reply, Reply in thread, Copy, Pin, Save, and Edit and Delete for your own messages or Report for others'. The "…" button in the navigation bar is now a native menu with Members, Pinned messages and Saved messages (with counts), Follow thread, and a Mute switch. Members, Pinned and Saved open as native sheets that can be pulled to half or full height; touch and hold a row to remove a member, copy or unpin a message, or remove it from saved, and empty lists show the system empty state. Deleting or reporting a message and removing a member ask in a native confirmation dialog instead of a pop-up alert, and a successful report gives a haptic tap instead of an alert.
- Replace the last Settings pop-up sheets with native pages. Adding or editing a memory, inviting people, a member or invitation, deleting your account, a conversation's notification level, the default model, API keys (view, test, replace, remove, add), subscription connections and webhooks (list, detail with deliveries and secret rotation, add) each open as their own Settings screen with a native form and a ✓ in the navigation bar. This removes a provider list that opened inside a sheet with more sheets on top. Native switches now use a grey "on" colour in dark mode, where the white text colour had made on and off look the same.
- Rebuild Settings as native iOS forms. The home page is a grouped list with an inline Appearance picker, and each section (Memories, Members, Models and connections, Billing, Notifications, Webhooks, Voice, Account, Help) opens as its own screen with the system back button and swipe-back, instead of swapping content inside one hand-drawn page. Notification banners and voice input use system switches, transcription retention is an inline picker, Billing shows labelled rows with readable status, and the notification prompt is a centred page. Account shows your real name and email (it fell back to "User" and a blank email when the account record lacked them), and renaming yourself works: the app no longer adds its token and user id to request bodies, which the profile route's strict validation rejected as "Invalid request".
- Rebuild Edit agent as a native iOS form. It now has a real navigation bar with Chat and a ✓ to save, and one grouped form for:
  - the creature's look
  - name and what the agent helps with
  - where it runs
  - model, picked from a menu grouped by provider
  - instructions
  - tool switches
  - who can use it
  - Archive

  This replaces the old hand-drawn page with its breadcrumb, washed-out switches and a separate "advanced" screen. Archiving an agent now returns you to Agents instead of to a thread that can no longer open. Agent threads no longer flash the route name `dm/[id]` while opening or show "Opening agent thread…" text. When an agent was archived, made private or removed, the thread now says so and offers Back to Agents, instead of "This agent thread is unavailable in this workspace." Unknown model providers show a capitalised name in model pickers.
- Rework the Agents tab and agent creation. The tab now opens with a quick row of creatures (Overlay first, then the agents you opened most recently on this device) above a list of every agent with what it is for and a live status: Working, Needs you or Ready to review. Creating an agent asks what it should help with (saved as its description and starting instructions), has a button that picks a random shape and colour, and confirms with a check in the navigation bar instead of a Create button. In an agent's chat, your messages now use that agent's colour. Empty states (Work, Files, Activity, turned-off features) sit in the middle of the visible screen instead of near the top.
- Make bottom sheets open the iOS way: the shade behind a sheet now fades in place while only the sheet slides up (and back down when it closes), instead of the shade sliding up with it. Applies to the Work task, schedule, move, picker and organization sheets and the agent editor picker. The native segmented control no longer gets clipped inside sheets.
- Put every screen's title in the navigation bar itself (tab titles sit on the same row as the bar buttons, sub-pages use an inline title), so screens no longer open with an empty band above the content. Every segmented toggle (Work filters, Activity filters, Extensions tabs, the new-task sheet, the model picker, the agent profile) is now the native iOS segmented control. Extensions, Archived, Workspace and the output and memory pages drop their old in-page header and drawer menu for the native bar. Fix Extensions crashing (skills, MCP servers and outputs now read the paginated list responses), keep the app opening when its remembered workspace is no longer available, show Work's unavailable state below the header, give Activity plain-text two-line previews and a creature empty state, and stop showing an empty "Recent" label in Files.
- Make mobile chat feel like a modern AI app: one rounded composer with a round send/stop button (the field clears as soon as you send), agent replies as plain reading-size text with copy, share and how long the agent worked underneath, the agent's creature looking around below a reply while it works, a wider tappable agent capsule in the header, a new-chat screen with suggestion cards, and a cleaner personal chat composer with model and tools chips. The Chats tab becomes a team inbox with shortcut cards (New chat, Activity, Automations, Archived) and collapsible Agents, Channels, Direct messages and Chats sections; the Agents tab becomes a grid of creature cards; Work and Files get creature empty states.
- Bring the agent creatures to the front of the mobile app: a welcome screen with drifting creatures, a four-step intro for new users (meet Overlay, agents on their own computer, delegating work, notifications) that ends in the Overlay chat and can be replayed from the account sheet, a visual new-agent sheet (name, creature shape and color) that opens the new agent's chat, an agent profile sheet from a tappable avatar capsule in the conversation header, and a creature greeting in empty agent chats.
- Replace the old silver orb app icon and launch screen with the approved Overlay mark (Libre Baskerville O with eyes): a light icon matching the web app icon plus iOS dark and tinted variants, an Android adaptive foreground, and a launch screen that shows the mark on the app background in light and dark mode.
- Give conversations a native iOS navigation bar: agent threads, DMs, channels, threads and personal chats show the name (with avatar or member count) and a system back button, agent thread actions move into a native menu, agent threads get a compact message field, the Chats list now includes personal chats alongside workspace chats and rooms, and the chat integration tests drive the Chats compose action instead of the removed sidebar.
- Rebuild the mobile shell on native iOS navigation: a Liquid Glass tab bar (Work, Agents, Chats, Files, Search) replaces the custom drawer and breadcrumbs, every tab gets a native navigation bar with large titles, system menus and search, a new Chats list with a native segmented filter replaces the drawer recents, and Automations, Extensions, Activity, Voice and Settings move into a native account sheet.
