Overlay is a private workspace where your team and its agents work together on
models, knowledge, tools, and files. These docs cover using the **web app**,
running your own **self-hosted** instance, and **building** on the Overlay API
and MCP server.

## Scope

- The web app under `src/app` and the `/api/v1` contracts behind it.
- The Convex backend that stores app data.
- Self-hosting and operations.

Overlay is available on the web. Desktop and mobile apps are not available yet.

## Source of truth

The web API reference is generated from `src/shared/schemas/api-boundary.ts`.
