# Overlay Docs

`docs/` is the Mintlify site root and contains publishable documentation for
Overlay across **web**, **desktop**, self-hosting, operator, API, and legal
topics.

## Edit Model

- Edit `.mdx` pages directly. There is no markdown-to-MDX sync step.
- `docs/openapi/overlay-web.openapi.json` is generated by `npm run docs:generate:api`.
- Runtime config examples in `docs/config/` are validated by `npm run docs:health`.
- Internal reports, design assets, audits, and migration notes live in `internal-docs/`.
- Numbered implementation phases, AWS rehearsals, fault-injection procedures,
  and customer-specific evidence must not be published from `docs/`.

## Structure

- `introduction.mdx` - docs home.
- `desktop/` - Overlay Desktop (macOS) install, permissions, security, troubleshooting.
- `start/` - quickstart and repository map.
- `configure/` - environment variables, runtime config, provider matrix, and feature gates.
- `develop/` - architecture, Convex workflow, customization, modules, and API source of truth.
- `deploy-operate/` - self-hosting, Docker/on-prem, release readiness, security, and tenancy.
- `api-reference/` - generated API reference entry points and workflow guides.
- `legal/` - licensing, self-hosting obligations, and security reporting.
- `snippets/` - imported MDX snippets only.
- `config/` - validated example runtime configs.

Private cloud-validation plans, numbered backend parity phases, implementation
status, and evidence requirements remain under `internal-docs/`.

## Checks

Run this before publishing docs changes:

```bash
npm run docs:check
```

For a faster local check without Mintlify validation:

```bash
npm run docs:health
```
