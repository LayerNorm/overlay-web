title: "Self-Hosting Obligations"
description: "Source, notice, and branding obligations for self-hosted Overlay deployments."
---

First-party material stored directly in this repository is licensed under `AGPL-3.0-only`. Separate submodules and third-party material retain their own licenses. Overlay trademarks are governed separately by `TRADEMARKS.md`.

Operators should:

- Keep `LICENSE`, `LICENSE.md`, `COPYRIGHT.md`, `NOTICE.md`, and applicable third-party notices with distributions.
- Preserve a prominent source-code link for network users. For modified deployments, link to the complete Corresponding Source for the exact running version—not merely LayerNorm's upstream repository.
- Use a distinct name, logo, domains, and visual identity for modified distributions unless LayerNorm gives written trademark permission.
- Run `npm run license:check` and review dependency-specific obligations before distributing containers, binaries, native apps, or managed deployments.
- Obtain a signed commercial license if the intended use requires rights outside the AGPL.

This note is not legal advice.
