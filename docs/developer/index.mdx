---
title: "Build on Overlay"
description: "Ways to connect your own tools, apps and agents to Overlay."
---

Overlay exposes your workspace to other software in three ways. Pick the one that matches what you are building.

<CardGroup cols={2}>
  <Card title="MCP" icon="plug" href="/help/connect-other-apps">
    Give ChatGPT, Claude, Cursor or any MCP client access to your chats, files, notes and agents.
  </Card>
  <Card title="REST API" icon="braces" href="/developer/api/overview">
    Call Overlay from your own code with an API key: conversations, files, automations and billing.
  </Card>
  <Card title="Bring your own agent" icon="bot" href="/help/other-agents">
    Run Claude Code, Codex or another agent on your machine and assign it work in Overlay.
  </Card>
  <Card title="Contribute" icon="git-branch" href="/developer/contribute/run-locally">
    Run Overlay from source, find your way around the repository and send a change.
  </Card>
</CardGroup>

Found a security problem? See [Reporting a vulnerability](/developer/security).
