---
title: "Build on Overlay"
description: "Ways to connect your own tools, apps and agents to Overlay."
---

Overlay exposes a workspace to other software in a few ways. Start with MCP unless you need something it does not cover.

<CardGroup cols={2}>
  <Card title="MCP" icon="plug" href="/developer/mcp">
    Give ChatGPT, Claude, Cursor or any MCP client access to notes, files, memory and agents.
  </Card>
  <Card title="REST API" icon="braces" href="/developer/api/overview">
    The `/api/v1` routes behind the web app: conversations, files, automations and more.
  </Card>
  <Card title="Bring your own agent" icon="bot" href="/help/other-agents">
    Run Claude Code, Codex or another agent on your machine and assign it work in Overlay.
  </Card>
  <Card title="Webhooks" icon="webhook" href="/developer/webhooks">
    Get a signed request at your endpoint when a chat or automation finishes.
  </Card>
</CardGroup>

Want to change Overlay itself? [Run it locally](/developer/contribute/run-locally) and read the [repository map](/developer/contribute/repository-map).

Found a security problem? See [Reporting a vulnerability](/developer/security).
