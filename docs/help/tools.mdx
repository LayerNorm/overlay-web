Tools are the things chat and agents can do for you. Each is grouped; an agent is given groups, and always acts with your access.

## Tool groups

| Group | What it does |
| --- | --- |
| **Memory** | Recall what Overlay knows about you and past conversations; save, update, and delete memories. |
| **Knowledge and files** | Search your knowledge bases and files; list and read files. |
| **File editing** | Create files and folders, move and rename. |
| **Notes** | List, read, create, append to, edit, update, and delete notes (Markdown). |
| **Skills** | List your skills and draft a new one from a conversation. |
| **Automations** | List, draft, create, update, pause, and delete scheduled automations. |
| **Image** and **Video** | Generate images; generate, animate, edit, and motion-control video. |
| **Web search** (paid) | Search the web, run deeper research, and read a page. |
| **Connected apps** | Use your connected apps (email, calendar, issue trackers…) through your accounts. |
| **MCP servers** | Find and call tools on the MCP servers you connected. A server can require approval per tool. |
| **Browser** (paid) | Drive an interactive browser for tasks that need a real site. |
| **Computer** (paid, opt-in) | Run commands and edit files on a persistent cloud computer. |
| **Agents** | Create and update agents from a conversation. |
| **Ask other agents** | Ask other agents, read their answers, and post into rooms. See [Agents](./agents). |

On the **free plan**, web search, the browser, and computers are shown but answer that they need a paid plan.

## Who gets which tools

- **Chat**: the same tools, shown as your request needs them. A base set (knowledge, memory, notes, skills) is always available; writes, files, the browser, video, and automations appear when you ask for them.
- **Overlay agents**: the groups you gave the agent. Narrowing an agent never gives it more than the workspace allows.
- **Claude Code and Codex agents**: your workspace through the **Overlay access** setting on the agent, minus computer tools (they have their own computer). See [Claude Code and Codex agents](./other-agents).
- **Other apps** (ChatGPT, Claude, Cursor): the access level you chose. See [Connect other apps](./connect-other-apps).

For developers: the full tool list and how it is built is in `docs/develop/tool-catalog.md` in the repository.
