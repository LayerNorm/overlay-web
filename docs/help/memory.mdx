---
title: "Memory"
description: "How to save, edit, and delete memories in Overlay."
---

Memories are durable facts, preferences, and instructions that Overlay can reuse across chats.

## Save a memory

1. In a chat, open the **Memory** panel.
2. Click **Add memory**.
3. Enter the fact and a category (optional).
4. Save.

## Edit or delete

- Open the memory panel.
- Click the memory you want to change.
- Edit the text or click **Delete**.

## Knowledge

Knowledge is created from files and notes. Overlay searches knowledge automatically when it answers questions. You can also ask directly:

```
Find the section on refund policy in my files.
```

## Privacy

Memories and knowledge are scoped to your account. They are not shared across users unless you explicitly share a project or file.
