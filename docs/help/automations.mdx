title: "Automations"
description: "Run instructions on a schedule, test them, and read what they did."
---

An automation is a set of instructions Overlay runs for you on a schedule: a Monday summary of open tasks, a daily check of a mailbox, a monthly report.

## Create one

1. Open **Automations** and create a new one.
2. Name it, and under **Instructions** write what it should do, as you would ask in a chat. A [skill](/help/extensions#skills) is a good way to reuse instructions.
3. Under **Schedule**, choose **Interval**, **Daily**, **Weekly** or **Monthly**, and the time.
4. Turn on **Enabled**.

**Flow** shows the automation's steps as a diagram you can edit.

You can also ask a chat or an agent to set one up ("every Friday, summarize what moved on the board"). An automation drafted inside an agent's chat belongs to that agent and runs with its instructions and tools.

## Test it

Under **Test**, choose **Run once** to try it immediately. Each run shows a timeline of what it did, what it produced and any errors.

## Keep track

- Past runs stay with the automation, so you can replay what happened.
- Turn off **Enabled** to pause the schedule without deleting anything.
- Archive an automation you no longer need; restore it from **Settings → Archived**.

Automations need a paid workspace to run on a schedule, and their usage is charged to the workspace's credit. See [Plans and credit](/help/billing).
