---
title: "Automations"
description: "How to create, test, and run scheduled automations in Overlay."
---

Automations are recurring AI workflows that run on your behalf.

## Create an automation

1. Open the **Automations** panel.
2. Click **New automation**.
3. Give it a name and instructions.
4. Choose a schedule: interval, daily, weekly, or monthly.
5. Save.

## Skills

Skills are reusable instruction templates. Create a skill for common tasks and use it in multiple automations.

## Test an automation

Before enabling the schedule, click **Run once** to test the automation. The result appears in the run history.

## Run history

- View past runs in the automation detail view.
- Click a run to see outputs and errors.
- Disable a schedule if the automation is not needed.
