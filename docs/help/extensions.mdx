**Extensions** (under **More** in the sidebar) is where you give Overlay and its agents access to more than your workspace. It has three parts: **Connectors**, **Skills** and **MCPs**.

## Connectors

Connectors link the apps you already use, such as email, calendar, documents and issue trackers. Choose a connector, sign in to that app, and its actions become tools for your chats and agents.

- **Personal** connectors use your own account in that app.
- **Workspace** connectors use one account shared by the whole workspace. It stays connected when the person who set it up leaves. Agents answering in a shared channel use only workspace connectors.

Disconnect a connector from the same page at any time.

## Skills

A skill is a saved set of instructions for a task you repeat: a report format, a review checklist, the way your team writes release notes. Choose **New skill**, give it a name and write the instructions. Chats and agents can use any skill you can see, and an agent can draft a new skill from a conversation.

Skills also show up as prompts in apps connected over MCP. See [Connect ChatGPT, Claude, and other apps](/help/connect-other-apps).

## MCP servers

If a tool you need speaks MCP, add it under **MCPs** with **Add server**: its address and, if it needs one, a key. Its tools then work in your chats and agents. You can require approval for each tool, so a chat asks before running it.

A server shared with the workspace runs with the credentials of the person who added it; other members can use its tools but never see the key.

## Who can share

Owners and admins choose whether members can share skills, MCP servers and connectors with the workspace, in **Settings → Workspace → Sharing & links** ("Anyone can share skills, MCP servers, and connectors").

For what each group of tools does, see [Tools](/help/tools).
