---
title: "Projects"
description: "How to organize chats, notes, and files into projects."
---

Projects help you group related chats, notes, files, and outputs.

## Create a project

1. Click the **+** next to Projects in the sidebar.
2. Enter a name and optional description.
3. Save.

## Add content

- Open a project.
- Click **New chat** to start a chat in that project.
- Upload files; they are stored in the project.
- Create notes linked to the project.

## Notes

- Notes are rich-text documents with markdown, slash commands, and project links.
- Use notes to capture context that can be reused across chats.

## Switch projects

Use the project selector in the sidebar or the project list to switch between projects. Your personal workspace is separate from projects.

## Share a project

Project owners can open **Settings**, find **Collaboration**, and select
**Manage access**. Grant a user, group, or custom role either viewer or editor
access.

- Viewers can open the project and its working content.
- Editors can change project working content.
- Only the owner can manage access or delete the project.
- Attached knowledge bases keep independent access rules. Sharing a project
  never grants access to a knowledge base automatically.
