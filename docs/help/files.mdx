The **Files** page (under **More** in the sidebar) has four views: **All**, **Notes**, **Files** and **Outputs**.

## Upload files

Choose **Upload**, or drag files onto the page. Overlay reads the text of documents so chats and agents can search them. Large files can take a moment before they show up in search.

Folders keep things tidy. Drag a file onto a folder to move it.

## Notes

Notes are documents you write in Overlay. Choose **New note** and start typing. Notes support headings, lists, tables, checklists, code, math (`$…$`) and embeds; type `/` for the full list.

Agents can read and edit notes too, when they have the Notes tools. Each edit is checked against the version the agent read, so it never overwrites your newer changes.

## Outputs

Images and videos that chats and agents generate are collected under **Outputs**.

## Personal or workspace

A file or note is created in the scope you are viewing. Personal items are only yours; Workspace items are visible to everyone in the workspace. Hover a row, or open its menu, to **Move** it to the other scope or **Archive** it. Select several files to move or archive them together.

## Find and restore

- Search from the top of the Files page, or press `⌘K` (`Ctrl+K`) to search everything.
- Archived files and notes are in **Settings → Archived**, where you can restore them or delete them for good.

## Storage

Storage limits depend on the workspace's plan. **Settings → Workspace → Billing** shows what you have used. See [Plans and credit](/help/billing).
