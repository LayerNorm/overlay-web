---
title: "Files"
description: "How to upload, search, share, and download files in Overlay."
---

## Upload files

1. Open a project or your personal workspace.
2. Click **Upload** or drag a file into the file list.
3. Wait for the file to be indexed. Large documents may take a few moments.

## Search files

- Type in the search box to search file names and content.
- Use the **Knowledge** panel to search semantically across all files.

## Share files

- Click a file and select **Share** to generate a link.
- Share links are scoped to your workspace. They respect the project and ownership rules.

## Download and outputs

- Click a file to preview or download.
- Generated images and videos appear in the **Outputs** panel.
