Questions, answered

How do I run all my AI agents from one place?

Overlay gives every agent a home in one workspace: agents you create in Overlay and agents you already use (Codex, Claude Code, Hermes) connect to the same roster with shared context, tools, and a computer to work from.

Can I bring my own agents to Overlay?

Yes. Connect agents running on machines you control. They join the same roster and receive workspace tools, context, and supervision through Overlay.

Where do Overlay agents work?

In the Overlay app and wherever work already happens: Slack, Telegram, iMessage, and the web. Agents can be scheduled or triggered, and they report back to the same place.

How do I control what agents can do?

Permissions, tool approvals, spend limits, run history, and audit trails apply to every agent on the roster, not just the ones Overlay runs.

Is Overlay open source?

Yes. The core is AGPL-3.0 with hosted and self-hosted options, plus commercial licensing for organizations that need different terms. The free tier needs no card.
